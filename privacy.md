# Privacy Policy — rclone-vps

Last updated: 2026-10-15

## Purpose
rclone-vps is a personal tool that synchronizes selected folders
from my OneDrive to my Google Drive using rclone on my private VPS.

## Google Drive data
The tool accesses file contents and metadata as needed for
synchronization. It can list, create, update, and delete files
in the configured destination folders.

## Storage and sharing
OAuth tokens are stored in the private rclone configuration
on my VPS. File data passes through the VPS during transfers.
Logs may contain file names and transfer details.

Data is processed through Microsoft OneDrive, my VPS provider,
and Google Drive as necessary for synchronization.
It is not sold, used for advertising, or published on this website.

## Control
I can stop synchronization and revoke the application's access
through my Google Account permissions.
Revoking access does not delete previously synchronized files.

## Contact
For questions, use the support email displayed on the Google
OAuth consent screen.
